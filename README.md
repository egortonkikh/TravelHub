# TravelHub Microservices Architecture

Проект демонстрирует работу микросервисной архитектуры для системы бронирования туров. Разработан в рамках финального проекта по дисциплине "Введение в DevSecOps".

## 🏗 Архитектура системы

Система состоит из 3-х микросервисов и одной базы данных:
1. **User Service** (порт 8000): Управление данными пользователей.
2. **Tour Service** (порт 8001): Каталог доступных туров.
3. **Booking Service** (порт 8002): Оформление бронирования. Проверяет существование пользователя и тура через HTTP-запросы к другим сервисам, затем сохраняет запись в БД.
4. **PostgreSQL** (порт 5432): Единая реляционная база данных для хранения всех сущностей.

## 🛠 Используемые технологии
- **Язык**: Python 3.9
- **Фреймворк**: FastAPI (Uvicorn)
- **База данных**: PostgreSQL 16
- **Контейнеризация**: Docker, Docker Compose
- **Драйвер БД**: psycopg2-binary

## 🚀 Инструкция по запуску

1. Убедитесь, что у вас установлен Docker и Docker Compose.
2. Склонируйте или перейдите в директорию проекта:
   ```bash
   cd travel_hub
   ```
3. Соберите и запустите все сервисы:
   ```bash
   docker compose up --build
   ```
4. Документация API (Swagger) доступна по адресам:
   - User Service: http://localhost:8000/docs
   - Tour Service: http://localhost:8001/docs
   - Booking Service: http://localhost:8002/docs

## 🔌 Эндпоинты

| Сервис  | Метод | Путь                  | Описание                    |
|---------|-------|-----------------------|-----------------------------|
| User    | POST  | `/users`              | Создать пользователя        |
| User    | GET   | `/users/{user_id}`    | Получить пользователя по ID |
| Tour    | POST  | `/tours`              | Добавить тур                |
| Tour    | GET   | `/tours/{tour_id}`    | Получить тур по ID          |
| Booking | POST  | `/bookings`           | Оформить бронирование       |
| Booking | GET   | `/bookings/{id}`      | Получить бронирование по ID |
